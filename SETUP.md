# Setup Guide

## Prerequisites
- A GitHub account with write access to this repository

## Steps
1. Go to **https://app.diagrams.net**.
2. On the start screen choose **Device/GitHub** storage: click **GitHub** (or **File → Open from → GitHub**).
3. Click **Authorize** and approve draw.io in the GitHub dialog. For private repositories, grant access to the repository/organization.
4. Select this repository (`8bit-Micro-services/drawio-diagrams`) and a branch.
5. Create a new diagram, or open an existing `.drawio` file.
6. Save with **Ctrl/Cmd+S** and choose a folder such as `architecture/`, `flowcharts/` or `network/`. Each save creates a commit.

## Direct link
- https://app.diagrams.net

## Opening a diagram by URL
`https://app.diagrams.net/#Uhttps%3A%2F%2Fraw.githubusercontent.com%2F8bit-Micro-services%2Fdrawio-diagrams%2Fmain%2F<path>`

## Troubleshooting
- *Repository not listed*: re-authorize and grant access to the repository.
- *Save fails on protected branch*: save to a feature branch and open a pull request.
