# Contributing

- Put diagrams in the matching folder (`architecture/`, `flowcharts/`, `network/`).
- Use descriptive lowercase, hyphenated names, e.g. `payment-service-flow.drawio`.
- Save as `.drawio` (uncompressed XML preferred, so diffs are readable).
- Use a branch and pull request for changes to existing diagrams.
- The *Validate diagrams* workflow checks that diagram files are well-formed XML.
